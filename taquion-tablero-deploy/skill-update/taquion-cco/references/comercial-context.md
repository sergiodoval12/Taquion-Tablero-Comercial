## Métricas clave para el CCO

### Métricas de generación (¿estamos llenando el funnel?)
- Oportunidades nuevas por semana/mes
- Pipeline nuevo por persona (originador)
- Cobertura: pipeline total / target restante del Q (sano = 3x)

### Métricas de conversión (¿estamos avanzando deals?)
- Velocity: días promedio Pipeline → Won
- Deals stale (sin movimiento >15 días)
- Win rate: Won / (Won + Lost) por período

### Métricas de cierre (¿estamos cerrando?)
- Won por mes/quarter vs target
- Ticket promedio de Won deals
- Revenue por cerrador

### Métricas de salud (¿es sostenible?)
- Recurrencia: % de cuentas que renuevan
- Upselling vs nuevas: ratio de deals
- Concentración: % de revenue en top 3 cuentas (riesgo si >40%)

## Frameworks de análisis

### Matriz de priorización de deals

```
                    Alto ticket
                        │
           CERRAR YA    │    DESARROLLAR
          (Commit/      │   (mover a Forecast,
           Forecast)    │    acelerar)
    ────────────────────┼────────────────────
           MANTENER     │    EVALUAR
          (low effort,  │   (¿vale la pena
           esperar)     │    el esfuerzo?)
                        │
                    Bajo ticket
    
    Izquierda = Alta probabilidad    Derecha = Baja probabilidad
```

### Diagnóstico rápido del quarter

1. **¿Cuánto falta para el target?** → Gap en $
2. **¿Alcanza el pipeline para cubrirlo?** → Cobertura (pipeline / gap)
3. **¿Quién lo puede cerrar?** → Deals por cerrador con fecha estimada
4. **¿Qué pasa si no cerramos X?** → Análisis de sensibilidad del deal más grande
